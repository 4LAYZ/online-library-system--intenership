INTRODUCTION ABOUT LIBRARY SYSTEM

An online library system is a digital platform where users can search, read and borrow books using the internet. It makes accessing learning materials easy, fast, and possible from anywhere.

Key facts
  • Established: 2019
  • Headquarters: Kigali, Rwanda
  • Governing body: ONLINE LIBRARY SYSTEM
  • Core mission: National library coordination and reading promotion
  • Flagship branch: ONLINE LIBRARY
